# 销售系统中文字段说明

## 一、客户表：`客户表`

| 字段名 | 含义 | 示例 |
| --- | --- | --- |
| `客户编号` | 唯一编号 | `CUS-0001` |
| `客户名称` | 客户公司或品牌名 | `杭州某品牌` |
| `产品类目` | 所属品类 | `美妆` |
| `团队规模` | 客户侧团队规模 | `6` |
| `当前合作方式` | 现有达人合作方式 | `手工建联 + Excel` |
| `月建联量` | 每月达人触达量 | `500` |
| `采购主体` | 实际采购公司 | `杭州某品牌有限公司` |
| `创建时间` | 创建时间 | ISO 时间 |
| `更新时间` | 更新时间 | ISO 时间 |

| `是否主要联系人` | 是否作为主要联系人 | `1` |
| `创建时间` | 创建时间 | ISO 时间 |
| `更新时间` | 更新时间 | ISO 时间 |

## 三、合作机会表：`合作机会表`

| 字段名 | 含义 | 示例 |
| --- | --- | --- |
| `机会编号` | 唯一编号 | `OPP-0001` |
| `客户编号` | 关联客户 | `CUS-0001` |
| `主要联系人编号` | 主要联系人 | `1` |
| `线索来源` | 线索来源 | `Expo` / `Inbound` / `Referral` |
| `当前阶段` | 当前销售阶段代码 | `qualification` |
| `优先级` | A/B/C | `A` |
| `核心痛点` | 最关键的业务卡点 | `找达人慢；跟进断档` |
| `上次沟通摘要` | 上一次沟通的核心结论 | `客户愿意先看 ROI 案例` |

| `预计推进天数` | 预计推进时长 | `14` |
| `内部负责人` | 你方负责人 | `Leo` |
| `下一步动作` | 明确的下一步动作 | `发送 ROI 案例并确认 Demo 时间` |
| `下一步日期` | 下一步动作日期 | `2026-03-28` |
| `是否已试用` | 是否进入试用 | `1` / `0` |

| `试用结束日期` | 试用结束日期 | `2026-04-14` |
| `报价版本` | 若已报价，对应版本 | `Pro Annual` |
| `最近联系时间` | 最近一次联系时间 | `2026-03-27T13:20:00` |

| `创建时间` | 创建时间 | ISO 时间 |
| `更新时间` | 更新时间 | ISO 时间 |

## 四、推进目标表：`推进目标表`

| 字段名 | 含义 |
| --- | --- |
| `目标编号` | 自增编号 |
| `机会编号` | 关联合作机会 |
| `目标内容` | 例如：触达量、有效回复率、寄样推进率 |

## 五、跟进记录表：`跟进记录表`

| 字段名 | 含义 |
| --- | --- |
| `记录编号` | 自增编号 |
| `机会编号` | 关联合作机会 |
| `记录时间` | 跟进发生时间 |
| `沟通方式` | 微信、电话、面谈、会议等 |
| `预约时间` | 下次已约定的见面/沟通时间 |
| `记录内容` | 本次沟通发生了什么 |
| `跟进结果` | 本次跟进得到的结果 |

## 七、最低必填字段

每条活跃合作机会至少要有：

- `客户名称`
- `线索来源`
- `当前阶段`
- `优先级`
- `下一步动作`
- `下一步日期`

缺一个，都说明这条机会还不够可管理。
