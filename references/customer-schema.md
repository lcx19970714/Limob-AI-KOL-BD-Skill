# 销售系统字段说明（最新）

## 一、客户表：`客户表`

| 字段名 | 含义 | 示例 |
| --- | --- | --- |
| `客户id` | 客户主键（int8） | `1` |
| `客户名称` | 客户公司或品牌名 | `杭州某品牌` |
| `产品类目` | 所属品类 | `美妆` |
| `团队规模` | 客户侧团队规模（选填） | `6` |
| `当前合作方式` | 现有达人合作方式 | `手工建联 + 表格管理` |
| `月建联量` | 每月达人触达量 | `500` |
| `采购主体` | 实际采购公司 | `杭州某品牌有限公司` |
| `创建时间` | 创建时间 | 标准时间字符串 |
| `更新时间` | 更新时间 | 标准时间字符串 |

## 二、联系人表：`联系人表`

| 字段名 | 含义 | 示例 |
| --- | --- | --- |
| `联系人id` | 联系人主键（int8） | `1001` |
| `客户id` | 关联客户 | `1` |
| `联系人姓名` | 联系人姓名 | `王敏` |
| `微信号` | 联系人微信号（团队内唯一，空值不校验） | `wangmin_微信` |
| `手机号` | 联系人手机号（团队内唯一，空值不校验） | `13800138000` |
| `联系角色` | 联系人的岗位 | `市场负责人` |
| `是否决策人` | 当前联系人是否拍板 | `1` / `0` |
| `决策关系说明` | 决策链说明 | `创始人拍板，我来推进` |
| `创建时间` | 创建时间 | 标准时间字符串 |
| `更新时间` | 更新时间 | 标准时间字符串 |

联系人去重顺序（服务层）：

1. `微信号`
2. `手机号`
3. `客户id + 联系人姓名`

## 三、合作机会表：`合作机会表`

| 字段名 | 含义 | 示例 |
| --- | --- | --- |
| `合作机会id` | 合作机会主键（int8） | `5001` |
| `客户id` | 关联客户 | `1` |
| `主要联系人id` | 主要联系人 | `1001` |
| `线索来源` | 线索来源 | `展会` / `主动咨询` / `转介绍` |
| `当前阶段` | 当前销售阶段 | `资格判断` |
| `优先级` | 机会优先级 | `A`（高优先级） |
| `核心痛点` | 最关键的业务卡点 | `找达人慢；跟进断档` |
| `上次沟通摘要` | 上一次沟通的核心结论 | `客户愿意先看投入产出案例` |
| `客户想法` | 客户当前的真实想法、顾虑或关注点 | `担心稳定性，愿意先试一个产品线` |
| `预计推进天数` | 预计推进时长 | `14` |
| `内部负责人` | 你方负责人 | `Leo` |
| `下一步动作` | 明确的下一步动作 | `发送投入产出案例并确认演示时间` |
| `下一步日期` | 下一步动作日期 | `2026-03-28` |
| `是否已试用` | 是否进入试用 | `1` / `0` |
| `试用状态` | 当前试用状态 | `未试用` / `试用中` / `试用完成` |
| `试用开始日期` | 试用开始日期 | `2026-04-02` |
| `试用结束日期` | 试用结束日期 | `2026-04-14` |
| `报价版本` | 若已报价，对应版本 | `专业版-年付` |
| `备注` | 其他补充说明 | `先试一个产品线` |
| `创建时间` | 创建时间 | 标准时间字符串 |
| `更新时间` | 更新时间 | 标准时间字符串 |

## 四、跟进记录表：`跟进记录表`

| 字段名 | 含义 |
| --- | --- |
| `记录id` | 跟进记录主键（int8） |
| `合作机会id` | 关联合作机会 |
| `记录时间` | 跟进发生时间 |
| `沟通方式` | 微信、电话、面谈、会议等 |
| `预约时间` | 下次已约定的见面/沟通时间 |
| `记录内容` | 本次沟通发生了什么 |
| `跟进结果` | 本次跟进得到的结果 |

## 五、最低必填字段

每条活跃合作机会至少要有：

- `客户id`
- `线索来源`
- `当前阶段`
- `下一步动作`
- `下一步日期`

说明：
- `优先级` 可由后端自动评级，不强制手填。
- 新建合作机会建议同时传 `客户id` 与 `联系人id`，保持机会与客户/联系人强关联。
